# 39rakrinCoding
ใช้ในการเรียนการสอนของวิชาเรียนเขียนโปรแกรมคอมพิวเตอร์ รหัสวิชา ว31295

21 พค.69เรียนเกี่ยวกับการแนะนำตัวโดยใช้สั่งprint
28/05/69 ฝึกทำแบบฝึกหัด input /คำนวณ
11/25/69 ทำโปรแกรมค่าใช้จ่าย
15/06/69ได้เรียนรู้เกี่ยวกับภาษาที่ใช้ในการเขียนโค้ด
18 มิ.ย/69เรียนเกี่ยวกับโปรแกรมรวมคะแนนแล้วการใช้ตัวแปรและโค้ดต่าง
22 มิ.ย/69ทบทวนการเขียนโค้ดและการเขียนโปรแกรมและคำสั่ง
